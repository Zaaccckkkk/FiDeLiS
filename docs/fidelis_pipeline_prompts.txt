FiDeLiS Internal Pipeline Prompts
==================================

Scope
-----
This file is generated from the original FiDeLiS pipeline prompt files under src/prompts/.
It excludes the vanilla_baseline prompts added for the separate zero-shot experiment.

How the pipeline sends prompts
------------------------------
src/utils/llm_backbone.py::LLM_Backbone.get_completion builds every chat call as:
  1. {"role": "system", "content": prompt["system"]}
  2. all entries in prompt["examples"]
  3. {"role": "user", "content": prompt["prompt"]}
The chat completion uses temperature=0 and top_p=0.

Pipeline order in src/llm_navigator.py
--------------------------------------
1. planning(): calls plan_prompt to produce keywords, planning_steps, and declarative_statement.
2. Path_RAG.get_path(): does not use a chat prompt; it embeds the LLM-generated keywords and ranks KG relations/neighbors by embedding similarity.
3. deductive_termination(): for non-root paths, first calls reasoning_path_parser_prompt, then either terminals_prune_single_prompt or deductive_verifier_prompt depending on --verifier.
   The default CLI value is --verifier deductive+planning.
4. decide_top_k_candidates(): calls beam_search_prompt to choose beam indices from candidate paths.
5. reasoning(): calls reasoning_prompt to produce the final answer from the selected reasoning paths.

Faithfulness-relevant observation
-------------------------------
The final answer prompt for WebQSP/CWQ explicitly says the model should answer based on the reasoning path "and your knowledge".
The CR-LT system message asks for True/False, but the CR-LT final user prompt still says "based on the reasoning path and your knowledge".
Therefore, the current pipeline prompt does not force answers to be exclusively entailed by the KG path.
